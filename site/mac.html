ติดตั้ง Leonida Sub TH บน Mac

ต้องใช้ Mac ชิป Apple Silicon (M1 ขึ้นไป) และ macOS 14 Sonoma ขึ้นไป

ตั้งค่าครั้งแรกประมาณ 5 นาที
ดาวน์โหลดสำหรับ Macฟรี · Apple Silicon · macOS 14+ · LeonidaSubTH-mac.zip

ใช้ Windows? วิธีติดตั้ง Windows

สารบัญ

  1. ดาวน์โหลดและแตกไฟล์

  4. เปิดสิทธิ์ Screen Recording
  5. ไอคอนบนแถบเมนู + ปุ่มลัด

1ดาวน์โหลดและแตกไฟล์

  1. 1กด ดาวน์โหลดสำหรับ Mac เพื่อดาวน์โหลดไฟล์ LeonidaSubTH-mac.zip (หรือรับจากห้อง #ดาวน์โหลด-mac ใน Discord)
  2. 2ดับเบิลคลิกไฟล์ zip เพื่อแตกไฟล์ จะได้แอป LeonidaSubTH.app
    • ถ้าโหลดด้วย Safari จะแตกให้เองอัตโนมัติ

2ย้ายไปไว้ใน Applications

  1. 1ลาก LeonidaSubTH.app ไปวางในโฟลเดอร์ Applications
    • โฟลเดอร์ Applications อยู่ในเมนูด้านซ้ายของ Finder
    • อย่าเปิดแอปจากโฟลเดอร์ Downloads ตรง ๆ

3เปิดครั้งแรก

แอปยังไม่ได้เซ็นรับรองแบบเสียเงิน macOS จึงบล็อกตอนเปิดครั้งแรก ทำตามนี้ครั้งเดียว

  1. 1ดับเบิลคลิกแอปหนึ่งครั้ง
    • จะมีหน้าต่างบอกว่าเปิดไม่ได้ ให้กด Done หรือ ตกลง
  2. 2ไปที่ System Settings › Privacy & Security แล้วเลื่อนลงล่างสุด
  3. 3กด Open Anyway ข้างชื่อ LeonidaSubTH
  4. 4ใส่รหัสผ่านเครื่อง แล้วกด Open
ไม่มีปุ่ม Open Anyway? ใช้ Terminal แทน

สำหรับคนที่ใช้ Terminal เป็น: ลบแท็กกักกันด้วยคำสั่งนี้ แล้วเปิดแอปใหม่

xattr -dr com.apple.quarantine /Applications/LeonidaSubTH.app

เปิดครั้งแรกต้องต่อเน็ต

  • แอปจะโหลดคลังคำแปลไทยให้อัตโนมัติ (ครั้งเดียว)
  • หลังจากนั้นแอปเช็กอัปเดตเองทุกครั้งที่เปิด

4เปิดสิทธิ์ Screen Recording

แอปต้องอ่านภาพซับจากหน้าต่างเกม จึงต้องได้สิทธิ์ Screen Recording

  1. 1เปิดแอป จะมีหน้าต่างแนะนำ 3 ปุ่ม
    • เปิดการตั้งค่า: พาไปหน้า Screen Recording
    • เปิดแอปใหม่: กดหลังเปิดสวิตช์ เพื่อให้สิทธิ์มีผล
    • ปิด: ปิดหน้าต่างนี้
  2. 2กด เปิดการตั้งค่า หรือไปที่ System Settings › Privacy & Security › Screen Recording
  3. 3เปิดสวิตช์ของ LeonidaSubTH
  4. 4กด เปิดแอปใหม่
    • สิทธิ์จะมีผลหลังปิดแอป (Quit) แล้วเปิดใหม่เท่านั้น

สำคัญ: หลังอัปเดตแอป macOS จะถามสิทธิ์ใหม่ทุกครั้ง

  • ถ้าสวิตช์เปิดอยู่แล้วแต่แอปยังถาม ให้ลบ LeonidaSubTH ออกจากรายการด้วยปุ่ม −
  • เพิ่ม LeonidaSubTH กลับเข้าไปใหม่ แล้วกด เปิดแอปใหม่

macOS 15 ขึ้นไป

  • จะเด้งถามประมาณเดือนละครั้งว่า “ให้บันทึกหน้าจอต่อไหม” ให้กด Allow (อนุญาต) ตามปกติ

5ไอคอนบนแถบเมนู + ปุ่มลัด

แอปนี้ไม่มีไอคอนใน Dock แต่อยู่บน แถบเมนู มุมขวาบนของจอ ระหว่างเล่นเกมให้คลิกไอคอนนั้นเพื่อสั่งงาน

  • เปิดหน้าต่างหลัก
  • แสดงซับ
  • เลือกหน้าต่าง + กรอบซับ
  • ขนาดตัวอักษร
  • จอซับแยก
  • ออก
  • ⌘1
    เปิด/ปิดซับ
  • ⌘2
    เลือกหน้าต่าง + กรอบซับ
  • ⌘3
    ขนาดตัวอักษร · กดวนเล็ก–กลาง–ใหญ่
  • ⌘4
    จอซับแยก · สำหรับดึงเข้า OBS ตอนสตรีม

ปุ่มลัดใช้ได้เฉพาะตอนหน้าต่างหลักอยู่ด้านหน้า

  • ระหว่างเล่นเกม ใช้ไอคอนบนแถบเมนูแทน ⌘1–⌘4

6ตั้งค่า OBS

ให้ภาพเกมขึ้นใน OBS ก่อน (จากการ์ดแคปเจอร์ หรือหน้าต่าง PS Remote Play) แล้วทำตามนี้

  1. 1ใน OBS คลิกขวาที่พรีวิว → Windowed Projector (Preview)
  2. 2ขยายหน้าต่าง Projector ให้ใหญ่พอที่ซับอ่านออกชัด
    • ซับเล็กเกินไป OCR จะอ่านพลาด
  3. 3คลิกไอคอนบนแถบเมนู → เลือกหน้าต่าง + กรอบซับ (⌘2) แล้วเลือกหน้าต่าง Projector
    • รายการรวมหน้าต่างจากทุกเดสก์ท็อป (Space) เช่น OBS Projector ที่เปิดเต็มจอ
  4. 4ลากกรอบให้คลุมบริเวณซับ

ดูจาก YouTube บน Safari

  • กดเต็มจอที่ตัววิดีโอ Safari จะแยกเป็นหน้าต่างชื่อ “Safari” ให้เลือกหน้าต่างนั้น
  • เสถียรกว่า: ขยายหน้าต่าง Safari หรือใช้โหมดโรงภาพยนตร์ (กด t) แทน

เอาซับไทยขึ้นสตรีม

  1. 1เปิดจอซับแยก (⌘4)
  2. 2OBS: เพิ่มแหล่งภาพ macOS Screen Capture → โหมด Window
  3. 3เลือกหน้าต่าง Leonida Sub TH — Subtitles
  4. 4ตัดพื้นหลังสีเขียว/ดำออกด้วย Chroma Key หรือ Color Key

7อัปเดตแอป

ตั้งแต่ v1.7.0 beta ขึ้นไป แอปบน Mac สามารถอัปเดตตัวเองได้จากในโปรแกรม (ต้องวางแอปไว้ใน Applications)

  1. 1เมื่อมีเวอร์ชันใหม่ กดปุ่ม อัปเดตเลย ในแอป โปรแกรมจะดาวน์โหลด ตรวจไฟล์ และติดตั้งเวอร์ชันใหม่ให้อัตโนมัติ
  2. 2สำหรับเวอร์ชันเก่ากว่า 1.7.0 ให้กด ดาวน์โหลดสำหรับ Mac เพื่อโหลดไฟล์ zip ใหม่ แล้วลากแอปไปวางทับใน Applications (เลือก Replace)

คลังคำแปลอัปเดตให้อัตโนมัติ ไม่ต้องทำอะไร · หลังอัปเดตอาจต้องเปิดสิทธิ์ Screen Recording ใหม่
